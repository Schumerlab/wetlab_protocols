After each sequencing run:
1. Log flow cell usage using the ONT Flowcell Log
2. Wash the flow cell and add storage buffer according to ONT's protocol, which can be found on Dropbox:

```Schumer_lab_resources/Protocols/nanopore/flow-cell-wash-kit-exp-wsh004-document-document-PromethION-en-WFC_9120_v1_revQ_08Dec2020-23.pdf```

The Altemose Lab has found that the following protocol modification helps with pore recovery:<br> 
**Instead of just injecting the wash and letting it sit, we aspirate up and down lightly at each injection.**
